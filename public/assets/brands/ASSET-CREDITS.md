# Local brand asset sources and credits

These assets are stored locally so the website does not load third-party logos at runtime.

- `android-robot.svg` — Android Developers official flat robot-head vector: https://developer.android.com/static/images/brand/android-head_flat.svg. Android robot attribution required by the current Android brand guidelines: “The Android robot is reproduced or modified from work created and shared by Google and used according to terms described in the Creative Commons 3.0 Attribution License.” Guidelines: https://developer.android.com/distribute/marketing-tools/brand-guidelines
- `apple-logo.svg` — Apple logo vector extracted without path changes from the Apple website global navigation SVG at https://www.apple.com/. The `viewBox` is tightened to remove navigation whitespace; Apple retains its trademarks.
- `kitsune-mask-source.png` — Kitsune Mask project mark from the archived KitsuneMagisk source repository, https://github.com/1q23lyc45/KitsuneMagisk/blob/kitsune/docs/images/logo.png. The project credits original author HuskyDG and is GPL-3.0; see `KitsuneMagisk-LICENSE.txt`. The site clips the image to show only the mask symbol, not its wordmark.
- `google-pay-mark.svg` — Google Pay official mark from https://developers.google.com/static/pay/api/download-assets/Google-Pay-Acceptance.zip. Guidelines: https://developers.google.com/pay/india/api/web/brand-guidelines. Used as a visual UPI-compatible brand mark only; it does not add or claim a Google Pay API checkout integration.
- `binance-pay.png` — Binance wordmark image captured from the official Binance Pay website’s own page header: https://pay.binance.com/en. The UI pairs it with the existing “Pay” label; it does not imply a new Binance API integration.
- `usdt-tether-mark.svg` — Tether’s official green logo mark: https://tether.to/images/logoMarkGreen.svg. Source and trademark terms: https://tether.to/en/media/.

The brands remain the property of their respective owners. Use these marks only to identify the corresponding supported device/category or already configured payment option; do not imply sponsorship or endorsement.
